# Определения терминов по оперативной памяти

1. DDR (Double Data Rate) — двойная скорость передачи данных. Это тип оперативной памяти, который передаёт данные два раза за один такт: и по фронту, и по спаду сигнала. За счёт этого скорость работы получается в два раза выше, чем у обычной SDR-памяти. Существуют разные поколения: DDR, DDR2, DDR3, DDR4, DDR5, каждое следующее быстрее и энергоэффективнее предыдущего.

2. DIMM (Dual In-line Memory Module) — модуль оперативной памяти в виде планки, которая вставляется в специальный слот на материнской плате. Контакты у неё расположены с двух сторон, но работают как единая шина. Это стандарт для настольных компьютеров, а для ноутбуков используется уменьшенная версия под названием SO-DIMM.

3. Ранг (rank) — группа чипов памяти на одном модуле DIMM, которые обращаются к шине данных одновременно. Один ранг занимает 64 бита. Модули бывают одноранговые (1R), двухранговые (2R) и четырёхранговые (4R, в основном в серверах). Чем больше рангов на планке, тем больше на ней памяти, но тем выше нагрузка на контроллер памяти.

4. CAS Latency (CL) — задержка между моментом, когда контроллер памяти отправляет запрос на чтение, и моментом, когда данные реально становятся доступны. Измеряется в тактах. Например, CL16 значит, что после команды чтения нужно подождать 16 тактов. Чем меньше это значение, тем быстрее отклик памяти.

5. Тайминги — набор из нескольких задержек в тактах, которые вместе описывают скорость работы памяти. Обычно записываются четырьмя числами, например 16-18-18-38. Первое число — это CL (задержка чтения). Второе — tRCD (задержка между открытием строки и чтением колонки). Третье — tRP (время закрытия одной строки и открытия другой). Четвёртое — tRAS (минимальное время активности строки). Чем меньше тайминги при той же частоте, тем быстрее работает память.

6. Двухканальный режим (Dual Channel) — режим работы контроллера памяти, при котором два модуля DIMM работают параллельно и шина данных удваивается с 64 до 128 бит. Это даёт прирост производительности примерно на 10–30 процентов в задачах, которые чувствительны к пропускной способности памяти, например в играх, рендеринге и архивации. Чтобы этот режим работал, нужно два или четыре одинаковых модуля, установленных в правильные слоты на материнской плате (обычно через один, например A2 и B2).
